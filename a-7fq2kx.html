Casta CapsPANEL DE ADMINISTRACIÓN

Primera vez en este celular. Crea la clave del panel y pega tu llave de GitHub (token). La llave se guarda cifrada con tu clave y solo en este celular.

¿Cómo saco la llave de GitHub?
  1. Entra a github.com con la cuenta GorrasCasta → foto de perfil → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
  2. Nombre: "Panel Casta". Expiración: 1 año.
  3. Repository access: "Only select repositories" → GorrasCasta.github.io.
  4. Permissions → Repository → Contents: Read and write (lo demás se queda igual).
  5. Generate token, copia la llave y pégala aquí. No la mandes por WhatsApp ni la compartas.
